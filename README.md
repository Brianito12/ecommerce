# 🛒 E-Commerce Web Application

## 📌 Overview
A responsive full-stack e-commerce web application built using Html, Javascript, and CSS. This project demonstrates modern frontend development practices and responsive UI design.

---

## 🚀 Features
- Product listing interface
- Responsive design (mobile & desktop)
- Clean and modern UI
- Component-based architecture
- Interactive user experience

---

## 🛠️ Tech Stack
- Html
- JavaScript
- CSS
